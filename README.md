# ቦኖ አዲስ (Bono Addis) v2.6

Offline-first, Amharic-first Hotel & Restaurant **ቦኖ** control system for **Android APK**, **Telegram Mini App**, and **Plesk MySQL (`bono_*` tables)**.

## What's New in v2.6
1. **Weekly Software Update Banner:** Admin/Plesk publishes `APP_VERSION` + `APK_DOWNLOAD_URL`; APK & TMA users see a one-tap update prompt.
2. **Auto-Sync When Online:** Automatically syncs pending receipts, bono requests, and table turnovers whenever internet returns (plus manual `ላክ`).
3. **Waitress "Request More Bono (`ተጨማሪ ቦኖ ጠይቅ`)":** Sends a live request to Owner/Cashier with one-tap **`ፍቀድ እና ስጥ`** approval.
4. **Station Order Alarm + Notes:** Plays an offline Web Audio chime on `ወጥ ቤት` / `ባሪስታ` / `ስጋ ቤት` / `ቡና ቤት` screens with optional descriptive notes (`ማስታወሻ`).
5. **Visual Table Grid & Turnovers (`ዙር`):** Waitresses manage multiple tables (`ጠረጴዛ 1–10`), track live bills per table, and close tables to start the next turnover.
